MetaX

MetaX provides movie metadata and artwork from a self-hosted metaX backend. The backend does not require an API token. Use a Movies or Mixed content library for movie items, or a Shows library when each title is stored in its own folder.

Server

Full URL of the metaX backend, for example https://metax.example.com.

Library categories

Map each Jellyfin library to the metaX content category used for scraping. Unmapped libraries use the backend's normal routing defaults.

Provider cookies

Optional. Cookies are stored only in this plugin and sent to the configured metaX backend for the matching request. Leave a field blank to disable it.
